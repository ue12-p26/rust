When in need of a *cloud service* or an *application*, try to envisage a
European solution in order to support the development of EU-based companies,
nonprofit organizations and open source projects.
The [European Alternatives](https://european-alternatives.eu/) site lists
many European solutions classified in more than 60 categories. Be careful,
though, since some companies do not host data inside EU.

The French nonprofit organization [Framasoft](https://framasoft.org/)
provides also several solutions hosted in France.

Here are examples of solutions for some of the most used categories:

- Polling:
  - [Framadate](https://framadate.org/).
  - [Nuudel](https://nuudel.digitalcourage.de/).

- Source-code-hosting facilities:
  - [European version control services](https://european-alternatives.eu/category/version-control-services).
  - [Framagit](https://framagit.org/).

- Document collaboration:
  - [European document collaboration services](https://european-alternatives.eu/category/document-collaboration-services).
  - [Framacalc](https://framacalc.org/).
  - [Framapad](https://framapad.org/).
  - [Framaspace](https://www.frama.space/).

- Mapping:
  - [European navigation apps](https://european-alternatives.eu/category/navigation-apps).
  - [Framacarte](https://framacarte.org/).

- Calendar:
  - [European calendar services](https://european-alternatives.eu/category/calendar-services).
  - [Framagenda](https://framagenda.org/).
  - [Framaspace](https://www.frama.space/).

- Cloud storage:
  - [European file hosting services](https://european-alternatives.eu/category/file-hosting-services).
  - [Framaspace](https://www.frama.space/).

- Messaging:
  - [European instant messaging apps](https://european-alternatives.eu/category/instant-messaging-apps).
  - [Framatalk](https://framatalk.org/).

- Team communication:
  - [European team communication services](https://european-alternatives.eu/category/team-communication-services).
  - [Framateam](https://framateam.org/).
  - [Framaspace](https://www.frama.space/).

- Video conference:
  - [European video conferencing software](https://european-alternatives.eu/category/video-conferencing-software).
  - [Framaspace](https://www.frama.space/).

- [European web browsers](https://european-alternatives.eu/category/web-browsers).
- [European cloud computing platforms](https://european-alternatives.eu/category/cloud-computing-platforms).
- [European email providers](https://european-alternatives.eu/category/email-providers).
- [European file sharing services](https://european-alternatives.eu/category/file-sharing-services).
